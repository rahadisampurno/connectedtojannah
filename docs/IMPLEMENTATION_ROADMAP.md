# Implementation Roadmap

1. **Foundation + vertical slice (sekarang):** Next.js mobile-first/PWA, docs, tokens, onboarding, Home, Amalan, idempotent completion, Journey update, tests.
2. **Auth:** provider decision, registration/login, rotating refresh token, device sessions.
3. **Circles:** membership RBAC, invite token, server-side privacy projections, encouragement.
4. **Journey/Garden:** transparent modular layers, parallax, milestones, reduce-motion QA.
5. **Challenges/Celebration:** three target types, transactional idempotent event, realtime + push.
6. **Admin/content:** review lifecycle, moderation, audit logs.
7. **Hardening:** PostgreSQL/Redis/BullMQ, observability, load/accessibility/security tests.
8. **Hostinger:** TLS, migration, backup/restore drill, resource tuning, release checklist.
