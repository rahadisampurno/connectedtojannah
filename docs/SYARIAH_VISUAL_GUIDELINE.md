# Syariah Visual Guideline

## Hard constraints

- Tidak memvisualisasikan Allah atau para Nabi.
- Tidak menyebut gambar sebagai representasi literal Jannah.
- Al-Qur'an tidak menjadi collectible/dekorasi sembarangan.
- Ayat dan hadis harus punya sumber terverifikasi sebelum publish; gunakan placeholder berlabel jika belum.
- Environment menjadi hero. Figur manusia, bila perlu, kecil/abstrak, berpakaian sopan, tanpa pose sensual atau interaksi romantis fisik.
- Dilarang: pahala points, ranking kesalehan, loot box, gacha, coin/gem reward, dan klaim nilai amal.

## Review gate

Setiap raster generatif melewati: pemeriksaan konten terlarang, provenance/prompt, status reviewer, optimasi ukuran, dan perubahan status `draft` → `approved`. Build production menolak aset reviewable yang belum approved.

## Audit aset awal

`journey_world_hero_v1` memuat lingkungan malam, arsitektur geometris, taman, air, dan cahaya; tanpa karakter, kitab, teks suci, atau simbol reward. Status tetap `draft` sampai persetujuan manusia.
